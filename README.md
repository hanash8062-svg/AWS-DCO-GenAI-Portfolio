# AWS-DCO-GenAI-Portfolio

AWS DCO 인턴십 직무 이해를 위한 생성형 AI 활용 및 포트폴리오 제작 과정 산출물을 정리하는 학습형 포트폴리오입니다.

이 저장소는 실제 AWS 내부정보가 아니라 교육용 샘플 데이터와 수업 산출물을 정리하기 위한 공간입니다.

## 폴더 구조

- `01_dco_glossary/`: DCO 인프라 용어 사전
- `02_dco_profile/`: DCO 협업 유형 리포트
- `03_sop_analysis/`: SOP 분석 및 체크리스트
- `04_environment_setup/`: 로컬 환경 설치 인증
- `05_antigravity_cli/`: CLI 도구 실습
- `06_cli_file_automation/`: CLI 파일 자동화
- `07_log_analysis_script/`: Python 로그 분석
- `08_incident_analysis/`: 장애 상황 분석
- `09_incident_report/`: 장애대응보고서
- `10_stitch_dco_dashboard/`: DCO 학습 대시보드


## 보안상 포함하지 않는 정보

실제 계정정보, 비밀번호, 인증 토큰, 실제 회사 정보, 실제 장비 정보, 실제 IP 주소, 실제 티켓 번호는 포함하지 않습니다.
