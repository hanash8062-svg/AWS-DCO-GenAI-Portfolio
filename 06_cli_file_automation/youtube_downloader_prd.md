# 교육용 PRD: 한국어 유튜브 영상 저장 도구

## 1. 문서 목적

이 문서는 한국어 사용자를 위한 교육용 영상 저장 도구의 요구사항을 정리하기 위한 PRD입니다.

본 문서는 실제 상용 서비스 개발 목적이 아니라, CLI 파일 자동화 실습에서 요구사항 분석, 기능 정의, 보안 검토, GitHub 문서화를 연습하기 위한 교육용 문서입니다.

---

## 2. 참고 프로젝트

참고 프로젝트: KurtBestor/Hitomi-Downloader

Hitomi-Downloader는 여러 사이트의 이미지, 영상, 음악, 텍스트 다운로드를 지원하는 다운로드 관리자 형태의 오픈소스 프로젝트입니다.

해당 프로젝트의 특징을 참고하여, 본 실습에서는 한국어 UI, URL 입력, 저장 폴더 선택, 실행 상태 표시, 오류 메시지 안내 기능을 가진 간단한 교육용 프로토타입을 작성합니다.

---

## 3. 개발 목적

한국어 사용자가 본인 소유 또는 다운로드 허가를 받은 영상 URL을 입력하고, 저장 위치를 선택한 뒤, 간단한 버튼 조작으로 영상을 저장할 수 있는 교육용 프로그램 구조를 이해합니다.

---

## 4. 대상 사용자

- Python 기초를 배우는 학생
- CLI 및 파일 자동화 실습을 수행하는 수강생
- 한국어 UI 기반 프로그램 구조를 이해하려는 사용자

---

## 5. 핵심 기능

| 기능 | 설명 |
|---|---|
| URL 입력 | 사용자가 영상 URL을 입력합니다. |
| 저장 폴더 선택 | 사용자가 저장 위치를 선택합니다. |
| 권리 확인 체크 | 본인 소유 또는 다운로드 허가된 영상인지 확인합니다. |
| 다운로드 실행 | 버튼을 눌러 저장 작업을 시작합니다. |
| 상태 메시지 출력 | 진행 상태와 오류 메시지를 한국어로 보여줍니다. |
| 오류 처리 | URL 미입력, 폴더 미선택, 권리 확인 미체크 시 안내합니다. |

---

## 6. 제외 범위

본 교육용 프로그램에서는 아래 기능을 구현하지 않습니다.

- 로그인 우회
- DRM 우회
- 유료 콘텐츠 다운로드
- 비공개 영상 접근
- 계정 쿠키 사용
- 대량 자동 다운로드
- 실제 저작권 침해 가능성이 있는 콘텐츠 다운로드 유도
- 외부 사이트 보안 우회

---

## 7. 사용자 흐름

1. 프로그램을 실행합니다.
2. 영상 URL을 입력합니다.
3. 저장 폴더를 선택합니다.
4. “본인 소유 또는 다운로드 허가된 영상만 사용합니다” 항목을 체크합니다.
5. 다운로드 시작 버튼을 누릅니다.
6. 프로그램이 상태 메시지를 한국어로 출력합니다.
7. 오류가 있으면 한국어로 안내합니다.

---

## 8. 보안 및 준법 요구사항

- 사용자는 본인 소유 또는 다운로드 허가를 받은 영상만 대상으로 해야 합니다.
- 비밀번호, 인증 코드, API 키, 토큰, 계정 쿠키를 입력하지 않습니다.
- 로그인, DRM, 유료 콘텐츠, 비공개 콘텐츠 우회 기능을 제공하지 않습니다.
- 프로그램은 교육용 목적으로만 사용합니다.
- GitHub에는 실제 계정정보나 민감정보를 올리지 않습니다.

## 11. AI 답변 검증 메모

AI가 제안할 수 있는 기능 중 저작권 침해, 로그인 우회, DRM 우회, 비공개 콘텐츠 접근, 계정 쿠키 사용, API 키 입력을 요구하는 내용은 제외했습니다.

본 실습은 실제 콘텐츠 무단 다운로드 목적이 아니라, 오픈소스 프로젝트 분석과 PRD 작성, Python GUI 구조 이해를 위한 교육용 실습으로 제한했습니다.
