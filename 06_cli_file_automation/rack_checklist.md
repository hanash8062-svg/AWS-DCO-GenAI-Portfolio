## 3. 기록 메모

교육용 샘플 티켓에서는 SAMPLE_TOR_SW_01 장비에서 CRC error 증가 후 Link Down 이벤트가 관찰되었습니다.

현재 단계에서는 실제 원인을 판단하지 않고, 샘플 로그와 샘플 티켓에 표시된 내용만 기준으로 정리합니다.

보고서 초안에는 다음 내용을 포함합니다.

- 언제 발생했는가
- 어떤 샘플 장비에서 발생했는가
- 어떤 이벤트가 관찰되었는가
- 반복 여부 확인이 필요한가
- Ticket 상태는 무엇인가
- Escalation이 필요한가
