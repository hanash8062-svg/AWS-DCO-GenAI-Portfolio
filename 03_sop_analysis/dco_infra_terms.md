## 2. 내가 만든 DCO 인프라 용어 정의

### Rack

내 정의:

Rack은 서버나 네트워크 장비를 정리해서 넣어두는 장비 선반이라고 이해했다.
데이터센터에서는 여러 장비를 일정한 위치에 모아 관리하기 위해 사용되는 구조라고 생각하면 된다.

### Server

내 정의:

Server는 사용자의 요청이나 서비스를 처리하는 컴퓨터 장비라고 이해했다.
일반 PC와 비슷한 원리도 있지만, 데이터센터에서는 여러 사용자의 요청을 안정적으로 처리하는 역할을 한다.

### NIC

내 정의:

NIC는 서버가 네트워크에 연결되기 위해 사용하는 네트워크 카드라고 이해했다.
쉽게 말하면 서버가 다른 장비와 데이터를 주고받을 수 있게 해주는 연결 통로 역할을 한다.

### ToR Switch

내 정의:

ToR Switch는 랙 가까이에 위치해서 여러 서버의 네트워크 연결을 모아주는 스위치라고 이해했다.
각 서버가 따로따로 멀리 연결되는 것이 아니라, 랙 단위에서 네트워크 연결을 모아주는 장비라고 생각하면 된다.

### Link Down

내 정의:

Link Down은 네트워크 연결이 끊어졌거나 정상적으로 연결되지 않은 상태를 뜻한다고 이해했다.
다만 원인이 케이블인지, 포트인지, 설정인지 바로 단정하지 않고 발생 시간과 반복 여부를 먼저 확인해야 한다.

### CRC error

내 정의:

CRC error는 데이터가 이동하는 과정에서 오류가 감지된 상태라고 이해했다.
네트워크 연결이 완전히 끊어진 것은 아닐 수 있지만, 데이터 전송 품질에 문제가 있는지 확인이 필요한 신호라고 볼 수 있다.

### SSD failure

내 정의:

SSD failure는 저장장치인 SSD에 문제가 생겼거나 문제가 예상된다는 경고라고 이해했다.
실제 고장이라고 바로 단정하기보다, 경고 발생 시간, 반복 여부, 관련 로그를 확인해야 한다.

### Fan Alert

내 정의:

Fan Alert는 장비를 식혀주는 팬에 이상이 있을 수 있다는 경고라고 이해했다.
팬 문제는 온도와도 연결될 수 있기 때문에, 팬 경고와 온도 관련 이벤트가 같이 있는지 확인할 필요가 있다.

## 3. 헷갈리는 용어 비교

내가 비교한 용어:

Link Down vs CRC error

내가 이해한 차이:

Link Down은 네트워크 연결 자체가 끊어졌거나 연결 상태가 정상적이지 않은 경우를 말한다.
반면 CRC error는 연결은 되어 있을 수 있지만, 데이터가 오가는 과정에서 오류가 감지되는 경우를 말한다.

쉽게 말하면 Link Down은 “길이 끊어진 상태”에 가깝고, CRC error는 “길은 있지만 지나가는 물건이 중간에 손상되는 상태”에 가깝다고 이해했다.

아직 헷갈리는 부분:

둘 다 네트워크 문제처럼 보이기 때문에 처음에는 비슷하게 느껴졌다.
하지만 Link Down은 연결 상태 자체를 먼저 보는 표현이고, CRC error는 데이터 전송 중 오류가 감지되는 표현이라는 점을 구분해서 기억해야겠다.

## 5. AI 답변을 보고 내가 수정한 점

어려워서 쉽게 바꾼 표현:

AI 답변에서 “네트워크 인터페이스”, “전송 무결성”, “상위 스위치 연결” 같은 표현은 처음 보면 어렵게 느껴질 수 있다고 생각했다.
그래서 NIC는 “서버가 네트워크와 연결되기 위한 카드”, CRC error는 “데이터가 오가는 중 오류가 감지된 상태”처럼 쉬운 말로 바꾸었다.

실제 정보처럼 보일 수 있어 삭제하거나 수정한 표현:

실제 장비명, 실제 티켓 번호, 실제 IP 주소처럼 보일 수 있는 내용은 넣지 않았다.
예시가 필요할 때도 실제 환경처럼 보이는 이름보다는 SAMPLE, DEMO, EDU 같은 교육용 표현을 사용하는 것이 안전하다고 생각했다.

너무 단정적이라 바꾼 표현:

“SSD가 고장났다”, “케이블 문제다”, “팬이 고장났다”처럼 원인을 확정하는 표현은 피했다.
대신 “문제가 생겼거나 문제가 예상되는 상태”, “확인이 필요한 신호”, “관련 로그를 확인해야 하는 상태”처럼 바꾸었다.

아직 헷갈리는 용어:

Link Down과 CRC error가 아직 조금 헷갈린다.
둘 다 네트워크 문제와 관련된 표현이지만, Link Down은 연결 상태, CRC error는 데이터 전송 오류 감지라는 차이로 기억하려고 한다.

다시 공부하고 싶은 용어:

ToR Switch와 NIC를 더 공부하고 싶다.
둘 다 네트워크 연결과 관련이 있지만, NIC는 서버 쪽의 네트워크 카드이고 ToR Switch는 여러 서버의 연결을 모아주는 스위치라는 차이를 더 확실히 이해하고 싶다.

## 6. 오늘의 느낀 점

오늘 처음 알게 된 용어는:

랙 가까이에 위치해서 여러 서버의 네트워크 연결을 모아주는 장비라는 점이 인상적이었다.

가장 헷갈렸던 용어는:

가장 헷갈렸던 용어는 Link Down과 CRC error였다.
둘 다 네트워크 장애처럼 보이지만, 하나는 연결 상태의 문제이고 다른 하나는 데이터 전송 중 오류가 감지되는 상태라는 점을 구분해야 한다고 느꼈다.

AI 답변을 사용할 때 조심해야 할 점은:

AI 답변은 설명이 빠르고 편리하지만, 너무 전문적으로 쓰이거나 실제 내부정보처럼 보이는 예시가 들어갈 수 있다고 느꼈다.
그래서 그대로 복사하기보다는 내가 이해한 말로 바꾸고, 실제 장비명이나 티켓 번호처럼 보이는 내용이 없는지 확인해야 한다.

다음 차시에서 더 알고 싶은 내용은:

다음 차시에서는 SOP를 기준으로 문제 상황을 어떻게 정리하고, 어떤 경우에 Escalation이나 Incident Report로 연결되는지 더 알고 싶다.
특히 Link Down이나 CRC error 같은 샘플 상황을 보고 확인 순서를 정리하는 연습을 더 해보고 싶다.
